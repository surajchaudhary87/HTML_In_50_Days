Clickable Computer Image

Click the monitor, keyboard or mouse area in the image to open its information page.

Monitor

A monitor displays text, images and other computer output.

Keyboard

A keyboard is used to enter text, numbers and commands.

Mouse

A mouse helps you point, click and select items on a screen.

Important HTML Elements

  • <map> defines an image map.
  • <area> defines a clickable region.
  • usemap connects an image to a map.
  • shape defines the region's shape.
  • coords defines the region's coordinates.
  • href defines the destination.
  • alt describes the clickable area.
